# Changelog

## 0.1.0-candidate.1

Initial CANDIDATE release of the UGTP machine-readable standard.

### Added

- Canonical type definitions (JSON Schema Draft 2020-12)
- Canonical object schemas (UCI, UCA, Intent, ExecutionPlan, etc.)
- Request/response message schemas
- Event schemas (AsyncAPI 3.0)
- Error code definitions
- OpenAPI 3.1 REST API specification
- AsyncAPI 3.0 event specification
- TypeScript type generation from schemas
- Validation tooling
- Conformance test infrastructure
- Valid and invalid fixture examples
