# Security Policy

## Reporting

Report security vulnerabilities to security@norionsoft.com.

Do not open public issues for security vulnerabilities.

## Scope

This repository contains protocol definitions, not executable services.
Security issues here relate to schema ambiguities that could lead to
implementation vulnerabilities (e.g., missing validation constraints,
underspecified replay protection, ambiguous canonicalization rules).

## Response

We will acknowledge receipt within 48 hours and provide a timeline for resolution.
