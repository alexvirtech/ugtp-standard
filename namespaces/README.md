# Namespaces

Reserved UGTP namespaces for event channels, ID prefixes, and protocol extensions.

## Reserved Prefixes

| Prefix | Usage |
|--------|-------|
| `uci_` | Universal Crypto Identity |
| `uca_` | Universal Crypto Account |
| `int_` | Intent |
| `plan_` | Execution Plan |
| `step_` | Execution Step |
| `exec_` | Execution |
| `rcpt_` | Receipt |
| `cor_` | Correlation |

## Event Namespaces

| Namespace | Domain |
|-----------|--------|
| `ugtp.uci.*` | Identity events |
| `ugtp.uca.*` | Account events |
| `ugtp.account.*` | Account linking events |
| `ugtp.intent.*` | Intent lifecycle events |
| `ugtp.execution.*` | Execution events |
| `ugtp.receipt.*` | Receipt events |
